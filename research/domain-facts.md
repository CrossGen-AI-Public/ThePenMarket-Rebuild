## 4. Condition vocabulary

| Term | Meaning |
|---|---|
| Mint / NOS | unused, uninked |
| Near mint | inked or one tiny blemish; nib perfect |
| Excellent | all original; slight use, minor brassing, crisp imprints |
| User grade | works; visible wear, brassing, discoloration |
| Brassing | plating worn to base metal |
| Ambering | clear/celluloid yellowed (sac outgassing, ink) |
| Crazing | fine surface cracks, irreversible |
| Shrinkage | celluloid contracts; cap/barrel mismatch |
| Restored | new sac/seals, cleaned, nib tested |

No industry-wide scale: https://www.vintagepens.com/condition_scale.shtml ; https://www.peytonstreetpens.com/pen-grading/ .
