Add old addresses

Paste your list, one address per line. Full addresses (https://thepenmarket.com/…) and the part after the domain both work. To choose where one goes, put the new address after it on the same line, like /old-sheaffer-page.html /brand/sheaffer/. A line with only the old address is matched to the new page with the same name; any that can’t be matched are listed with a shop search you can keep or change, ready to paste back.

Each line is checked against the new site first, so nothing that already works gets changed. Up to 2,000 lines at a time.
